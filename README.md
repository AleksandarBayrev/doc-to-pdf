# doc-to-pdf
Program that converts from Word Document to PDF

## Configuration structure example for Windows
```json
{
    "inputFolder": "C:\\mydocs",
    "outputFolder": "C:\\output"
}
```

## Configuration structure example for Linux
```json
{
    "inputFolder": "/home/myuser/documents-to-merge",
    "outputFolder": "/home/myuser"
}
```
